Review(entry, rubric)

Four criteria, scored 1 to 8.

Equal weight, no middle. The entry score is the mean of the four, to one decimal. Five judges, about four entries each; the top entry in each group goes to the final.

rubric.md · 4 criteria · bands 1–2 / 3–4 / 5–6 / 7–8
Does it work
1–2Didn't run or is slides only
3–4Parts run; core flow incomplete
5–6Core flow works with bugs or rough edges
7–8Works end to end; a business could try it today
Ease of implementation for a small business
1–2Needs a developer and custom setup
3–4Needs technical help to get started
5–6A motivated owner could set it up with the README
7–8Plug-and-play; clear README, no code needed
Impact on the business's operations
1–2Unclear who it helps or how
3–4Helps a narrow task a little
5–6Saves real time or money on a common task
7–8Changes how a core part of the business runs
Creativity of the solution
1–2Generic chatbot or template
3–4Sensible but predictable
5–6A fresh angle on a known problem
7–8Something judges hadn't thought of
Highlighted rows are what judges are looking for.

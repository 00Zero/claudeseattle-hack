Read(theme.md)

What you'll build

The theme is practical: AI tools, workflows, and playbooks a small business can adopt without hiring a developer. Judges ask whether it works, whether an owner could set it up from the README, whether it changes how the business runs, and whether it is something they had not seen before.

Who's in the roomOwners, professionals, students, builders

A balanced team has at least one of each and someone hands-on with code.

What shipsA working tool with a README

Plus a repo and a demo video. Slides are optional; the demo is the point.

Where it goesOpen source, on GitHub

Every entry is public after the deadline, so a business can find it later.

Review(entry, rubric)

Judging criteria

Four criteria, equal weight, each scored 1 to 8 with no middle. An entry's score is the mean of the four, to one decimal. Five judges each score about four entries over dinner and send one to the final; all five score the finalists on stage.

Criterion1–23–45–67–8
Does it workDidn't run or is slides onlyParts run; core flow incompleteCore flow works with bugs or rough edgesWorks end to end; a business could try it today
